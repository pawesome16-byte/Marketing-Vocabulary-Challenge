# Marketing Vocabulary Challenge

A lightweight, standalone vocabulary quiz to help learners study marketing English through English definitions and Thai multiple-choice translations.

## Features

- **Five vocabulary units**
  - Unit 1: Fundamental Marketing Vocabulary
  - Unit 2: Advertising
  - Unit 3: Public Relations and Events
  - Unit 4: Sales Promotion
  - Unit 5: Direct Marketing and Internet Marketing
- **Two practice modes:** practise a selected unit or mix questions from all units.
- **Multiple choice:** choose the correct Thai translation from four options.
- **Quiz controls:** configure the number of questions and timer.
- **Scoring and feedback:** see whether each answer is correct.
- **Mistake review:** revisit words answered incorrectly.
- **Standalone:** designed to run in a modern browser without a server or build step.

## Getting started

1. Download or clone this repository.
2. Open `marketing_vocabulary_challenge.html` in a modern browser.
3. Choose a unit or mixed practice, configure the quiz, and start playing.

No package manager, account, or backend is required for the standalone version.

## GitHub Pages (optional)

To publish the game as a website:

1. Put `marketing_vocabulary_challenge.html` in the repository root.
2. Rename it to `index.html` (recommended for the default GitHub Pages landing page), or create an `index.html` that links to it.
3. In the GitHub repository, open **Settings → Pages**.
4. Choose the deployment source for your branch (usually `main`) and the root (`/`) folder, then save.
5. Wait for GitHub Pages to finish publishing and open the URL shown in the Pages settings.

## Learning approach

Each question presents an English definition and asks the learner to select its Thai meaning. For exam preparation, review the vocabulary and verify specialised definitions and translations against your course materials.

## Data and privacy

The standalone version does not require an account or a server. If the game saves progress in browser storage, that data stays in that browser on that device and does not automatically sync to other devices. Clearing browser data may remove locally saved progress.
